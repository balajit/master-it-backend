Change 8 — Add sidebar_status (3-state) to LessonResponse and PracticeResponse
File: src/schemas.py
The sidebar's ItemStatus is a 3-state enum: "completed" | "in_progress" | "not_started".
The existing ProgressStatus is 6-state. Add a computed sidebar_status field to both response
models that collapses the 6-state mastery status into the 3-state sidebar vocabulary:
class LessonResponse(BaseModel):
    ...
    sidebar_status: str = "not_started"   # ADD — "completed" | "in_progress" | "not_started"

class PracticeResponse(BaseModel):
    ...
    sidebar_status: str = "not_started"   # ADD
Add a helper in src/services/progress.py:
def to_sidebar_status(status: ProgressStatus) -> str:
    """Collapse 6-state ProgressStatus to the 3-state sidebar ItemStatus."""
    if status == ProgressStatus.MASTERED:
        return "completed"
    if status in (ProgressStatus.PRACTICED, ProgressStatus.FAMILIAR, ProgressStatus.ATTEMPTED):
        return "in_progress"
    return "not_started"   # covers NOT_STARTED and LOCKED
Populate sidebar_status wherever LessonResponse and PracticeResponse are constructed
(in services/learning.py and routers/v1.py).
